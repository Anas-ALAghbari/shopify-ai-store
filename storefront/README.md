# 🛒 Storefront App — Shopify AI-Powered E-Commerce Store & Shopping Agent

This application is the commercial-grade storefront web frontend for **Shopify AI-Powered E-Commerce Store & Shopping Agent**, built using **Next.js 14**, **TypeScript**, and **Tailwind CSS**.

---

## 🌟 Features

- **High-Conversion Storefront UI**: Dynamic Hero Section, Category Filtering, Product Grid, and Cart Drawer.
- **AI Shopping Assistant**: Real-time conversational product matching engine using natural language prompts.
- **Shopify API Integration**: Prepared for seamless GraphQL Storefront API integration and direct checkout routing.

---

## 🚀 Development Setup

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run dev server**:
   ```bash
   npm run dev
   ```

3. **Production build**:
   ```bash
   npm run build
   ```
